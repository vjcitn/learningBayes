    What we are building

    In the hackathon your class builds one working Shiny app for screening tests when we are unsure of the test's sensitivity (Se) and specificity (Sp). You describe each uncertainty with a Beta distribution, choose a target population (which fixes the prevalence), and the app shows what you should believe about the predictive values: the posterior distribution, point estimates (mean, median, MAP), and intervals (equal-tailed, shortest, highest-density region).

    • The six teams each write a different set of functions (Beta utilities, predictive values, intervals, MAP and HPD region, target populations, the plot).
    • Each team's tests turn green as its functions are implemented, and the matching message in the app disappears.
    • When all six are merged, every panel fills in and the integration tests pass. That is the goal.

    The warmups below are not the hackathon: they build the understanding you need to write those functions with confidence.
